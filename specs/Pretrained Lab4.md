Extraction de la Métrique du Volume (Le "Bulk")RAFT (Recurrent All-Pairs Field Transforms) / RAFT-PIVSource : Intégré dans torchvision (PyTorch) via torchvision.models.optical_flow.Pourquoi l'utiliser : RAFT est le modèle pré-entraîné de référence (développé par Princeton) pour l'estimation du flux optique. Vous lui passez les images de votre cuve, et il extrait le tenseur de vélocité de surface avec une précision sub-pixel, bien supérieure à l'algorithme Farneback classique d'OpenCV.UnLiteFlowNet-PIVLien : GitHub - erizmr/UnLiteFlowNet-PIVPourquoi l'utiliser : Un modèle d'apprentissage non supervisé optimisé pour la dynamique des fluides. Les PINNs pour le "Crash Algorithmique" (Manip P)DeepXDELien : GitHub - lululxvi/deepxdePourquoi l'utiliser : C'est le framework Open Source de référence pour les réseaux informés par la physique (compatible PyTorch, TensorFlow, JAX). Il contient déjà l'équation des ondes (Wave Equation) codée en dur.Votre Workflow : Vous n'avez pas besoin de chercher un modèle pré-entraîné spécifique. Vous prenez le template de l'équation d'onde 1D dans DeepXDE, vous modifiez l'équation pour ajouter votre terme de courant $(c^2 - v^2)\partial_x^2\phi - 2v\partial_x\partial_t\phi - \partial_t^2\phi = 0$, et le framework compile la fonction de perte physique (Physics Loss) automatiquement.NVIDIA ModulusLien : NVIDIA ModulusPourquoi l'utiliser : C'est une plateforme industrielle contenant des architectures de réseaux (Fourier Neural Operators, PINNs) pré-optimisées. L'Étranglement Holographique (Tensor Networks pour la Manip O)Google TensorNetworkLien : GitHub - google/TensorNetworkPourquoi l'utiliser : Les réseaux de neurones classiques (Dense/CNN) stockent trop d'informations de manière opaque. Pour prouver le principe holographique, votre réseau doit posséder un goulot d'étranglement sévère (la Bond Dimension $\chi$). Cette bibliothèque vous permet de construire des graphes de tenseurs (comme les MERA ou MPS, utilisés en recherche AdS/CFT) pour forcer mathématiquement la compression de vos 16 capteurs acoustiques (frontière) vers le tenseur vidéo (volume).
